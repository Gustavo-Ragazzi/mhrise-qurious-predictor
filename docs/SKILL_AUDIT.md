## Outstanding measurements

These gaps are explicitly displayed in the app. Use **Missing / partial values** in the Skills tab. Unverified quantities are not replaced with guessed values or values from other games.

- **Ballistics**: Range changes depend on ammo/arrow type and mods. Exact per-level distances have not been verified for this reference; no universal percentage is assumed.
- **Speed Eating**: The game describes faster item consumption, but exact per-level animation timings have not been verified for this reference.
- **Capture Master**: Can increase capture reward count. Exact activation probability has not been verified; it is not a guaranteed extra carve or reward.
- **Good Luck**: Increases quest/target reward counts. Exact per-level probabilities have not been verified; reward rates from other Monster Hunter games are not substituted.
- **Chameleos Blessing**: Numeric core or poison-duration bonus supplied; Spiribird/reward probability remains unverified.
- **Wind Alignment**: Numeric core or poison-duration bonus supplied; Spiribird/reward probability remains unverified.
- **Thunder Alignment**: Numeric core or poison-duration bonus supplied; Spiribird/reward probability remains unverified.
